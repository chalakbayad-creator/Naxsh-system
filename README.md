# Naxsh System (سیستەمی چاپی نەخش)

سیستەمی بەڕێوەبردنی چاپخانەی نەخش، بنیادنراو بە تەکنەلۆژیای مۆدێرنی React و TypeScript، بە دیزاینی تەواوی RTL و بەکارهێنانی فۆنتی فەرمیی کوردی NRT.

## تایبەتمەندییە سەرەکییەکان

1. **داشبۆردی مۆدیولەکان (Dashboard)**:
   - گەڕانی خێرا لە مۆدیولەکان بە کلیلەکانی `Ctrl + K`.
   - پەڕەبەندی زیرەک و ئەنیمەیشنی نەرم بە 10 مۆدیول بۆ هەر پەڕەیەک.
   - 11 مۆدیولی تایبەت (ئۆردەر، کڕین، کۆگا، دارایی، بەرهەمهێنان، چاپ و بڕین، کڕیاران، کارمەندان، ڕاپۆرتەکان، لەیبڵی گەیاندن، کڕیارە دڵسۆزەکان).

2. **بەڕێوەبردنی ئۆردەرەکان (Orders Pipeline)**:
   - هێڵی قۆناخەکانی ئۆردەر (نوێ، دیزاین، پەسەندکردن، چاپ، بڕین، ناردن).
   - پانێڵی کارە چالاکەکان و گەڕان بە کۆدی ئۆردەر، ناوی کڕیار یان تەلەفۆن.
   - بینینی وردەکاریی ئۆردەر، ئایتمەکان و ئاماری پێشکەوتنی قۆناخەکان.
   - دوگمەی پێشخستن بۆ قۆناخی دواتر بە شێوەی ڕاستەوخۆ.

3. **سیستەمی خێرای تۆمارکردنی ئۆردەر (POS Order Composer)**:
   - هەڵبژاردنی زیرەکی کڕیار بە گەڕانی ڕاستەوخۆ و تۆمارکردنی کڕیاری نوێ لە ڕێگەی مۆدالەوە.
   - ڕۆژژمێری کوردی بۆ هەڵبژاردنی دێدلاین و بەرواری تەواوبوونی کار (ئەمڕۆ، سبەی، دوای 3 ڕۆژ).
   - دیاریکردنی کاری بەپەلە (Urgent order).
   - پەنجەرەی هەڵبژاردنی کاڵاکانی کۆگا بە نرخ و وەسفەوە.
   - خشتەی ئایتمەکان بە دیاریکردنی ژمارە، تێبینی و دەستکاریکردنی نرخی دانە لەگەڵ ئاگاداریی دڵنیابوونەوە.
   - ژمێرەری خۆکاری داشکاندن (% یان IQD) و پیشاندانی سەب تۆتاڵ و کۆی گشتی.

4. **تەلارسازیی تەکنیکی (Tech Stack)**:
   - React 19 + TypeScript
   - Vite
   - RTL Layout & Custom Kurdish NRT Typography
   - In-memory & LocalStorage sync
