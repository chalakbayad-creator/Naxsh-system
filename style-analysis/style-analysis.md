## 2. فۆرمولای گشتی (هەردوو ڤیدیۆ یەک ئێسکەپەیکەریان هەیە)

```
[0–5s]   هووک: ڕستەیەکی شۆکهێنەر یان پرسیارێک + وەڵامی خێرا
[5–30s]  دانانی بابەت: ژمارەی گەورە + «ستەیک» (چی دەکەوێتە مەترسی؟)
[30s–1m] گەشتەکە/زانیارییە سەرسوڕهێنەرەکان، هەر ڕستەیەک = یەک وێنە
[~1m]    خاڵی وەرچەرخان (twist): «اوه اوه چی شده؟» / «اون لکه آبی رو می‌بینید؟»
[1–1:30] ڕوونکردنەوەی زانستی بە ٢–٣ ڕستەی سادە، بێ وشەی ئەکادیمی
[1:30–2] بەشی هەستی/شیعری: تەنیایی، ماڵ، کۆتایی، بێدەنگی
[2:00+]  کۆتایی فەلسەفی یان پرسیار بۆ کۆمێنت + لۆگۆ
```

- درێژی هەمیشە ~2:20 (کورتتر لە 3 خولەک → بۆ ڕیڵز/شۆرتس گونجاو).
- ~55–65 ڕستەی کورت، هەر ڕستەیەک 2–3 چرکە. نزیکەی **140–150 وشە لە خولەکێکدا**.
- ئاستی زانست: تەنها **یەک بیرۆکەی سەرەکی** لە هەر ڤیدیۆیەک (ڤیدیۆی ٢ تەنانەت ناوی ئەینشتاین و «ڕێژەیی» نایەت!). زانست دەکرێتە چیرۆک، نەک وانە.

## 3. شێوازی سیناریۆ و گێڕانەوە

### ڤیدیۆی ١ — «دۆکیۆمێنتاریی شیعری»، کەسی سێیەم
- **هووک بە کۆتایی جیهان**: «ئەو ڕۆژەی زەوی لەناو دەچێت...» → دواتر ناوی سوژەکە وەک ئاشکراکردنی نهێنی: «ڤۆیەجەر ١.» (ڕستەیەکی یەک‌وشەیی، وەستان، تێکستی زەردی گەورە).
- **بەکەسکردنی (personification) شتەکە**: ڤۆیەجەر «ماڵئاوایی» دەکات، «بیپ»ێکی لاواز دەنێرێت، «نامەبەری نەوەی مرۆڤ»ە، «ڕزگار» دەکرێت. شتێکی میکانیکی کراوە بە کارەکتەرێکی تەنیا و هەستیار.
- **ستەیک**: «ئەگەر بێگانە بیدۆزێتەوە، ئێمەش دەدۆزێتەوە» → بینەر پەیوەندیی کەسیی دەبێت.
- **قوتابخانەی کارل سەیگان**: «ئەو خاڵە شینە کاڵە دەبینن؟ ... بچووکتر لە یەک پیکسڵ» — ساتی هەستیی سەرەکی لە ناوەڕاستی ڤیدیۆ.
- **ئارکی هەست**: سەرسوڕمان → شانازی → تەنیایی → خەم (پاتری کز دەبێت، دەکوژێتەوە) → هیوا («کێ دەزانێت؟ لەوانەیە...»).
- **CTA**: پرسیارێکی دوولایەنە کە مشتومڕ دروست دەکات: «دەبێتە کێشە یان نا؟» → کۆمێنتی زۆر.

### ڤیدیۆی ٢ — «تۆ پاڵەوانی چیرۆکەکەیت»، کەسی دووەم + کاتی ئێستا
- **هووک سێ‌قۆناغی** لە 4 چرکەدا: پرسیار («دەتوانین؟») → وەڵامی دڵنیا («سەددەرسەد») → بەرەنگاری («بەڵام وێرەت هەیە؟»).
- **«بسیار خب»** وەک دەرگای چوونەژوورەوەی چیرۆک — دەنگ دەگۆڕێت بۆ ئاوازی گێڕەرەوە.
- **کەسی دووەم**: «سوارت دەکەم، دەگەیتە، ڕادەگریت، سەرسام دەبیت، دڵت تەنگ دەبێت» — بینەر خۆی لە کەشتییەکەدا دەبینێت (POV storytelling).
- **هەستی جەستەیی**: «هەوای فێنک، بێدەنگیی تەواو، شنەبا چیمەنزار دەخاتە سەما» — نووسینی سینەمایی، هەر ڕستەیەک دیمەنێکی ڕوون دروست دەکات بۆ وێنەی AI.
- **Twist لە خولەکی یەکدا**: «ئۆهۆ، چی بووە؟» + سێ پرسیاری یەک لە دوای یەک (ڕیتمی سێیی: زەوی، کیشوەر، مانگ).
- **ڕوونکردنەوە بە 3 ڕستە**: ٥ ملیۆن ساڵی ڕووناکی → کات بۆ تۆ هێواش بوو → بۆ زەوی ٥ ملیۆن ساڵ ڕۆیشت. هیچ هاوکێشە و ناوێکی زانستی نییە.
- **کۆتایی ئەخلاقی/فەلسەفی** کە زانستەکە دەکاتە وانەیەکی ژیان: «خۆت ویستت ئێستا بکەیتە قوربانیی داهاتوو.» — ڕستەیەکی کورت و تیژ کە دەمێنێتەوە لە مێشکدا.

### تایبەتمەندییە زمانییە هاوبەشەکان
- **تێکەڵەی نووسراو + قسەکراو**: ڕستەسازیی ئەدەبی (منظره‌ای که هیچ انسانی... ندیده) بەڵام کۆتاییەکان قسەیی (می‌مونه، می‌رسه، کوچیک، خونه). → بۆ سۆرانی: ڕستەسازیی جوان بەڵام بە شێوەزاری ئاسایی قسەکردن، نەک زمانی کتێب.
- **ڕستەی کورت** و **وەستانی بەئەنقەست** پێش ژمارە و ناوە گرنگەکان.
- **ژمارە وەک قارەمان**: ٤٩ ساڵ، ٤٠٬٠٠٠ ساڵ، ٦١٬٠٠٠ کم/ک، ٦ ملیار کم، ١ ڕۆژی ڕووناکی، ٢.٥ ملیۆن ساڵی ڕووناکی، ٩٠٪ — هەر ژمارەیەک لەسەر شاشە دەنووسرێت.
- **وشەی هەستی** لەتەنیشت زانست: تنها، خداحافظی، دلت تنگ می‌شه، خونه، سکوت مطلق، نجات.
- **ماڵ (خونه)** وەک وشەی کلیلی دووبارەبووەوە لە هەردوو ڤیدیۆدا — مۆتیفی ناوەندی کە زانستی دووری گەردوون دەبەستێتەوە بە هەستی مرۆڤ.
- **ئاوازی دەنگ**: نزم، هێمن، نیمچە‌چرپە لە بەشە هەستییەکاندا؛ خێراتر و وزەدارتر لە هووکدا. زەردەخەنە لە کاتی پرسیار.

## 5. تێمپلەیتی سیناریۆ بۆ کەناڵەکەت (بە کوردی)

```
هووک (0–5s):
  [ڕستەیەکی شۆکهێنەر یان پرسیار] + [وەڵامی یەک‌وشەیی] + [بەرەنگاری/نهێنی]
  نموونە: «دەتوانین مرۆڤێک بۆ هەمیشە لە بۆشاییدا ون بکەین؟ بەڵێ. بەڵام ئەوە چیرۆکێکی دڵتەزێنە.»

دانان (5–30s):
  سوژە بناسێنە بە 2 ژمارەی گەورە + بڵێ بۆچی گرنگە بۆ «ئێمە/تۆ».

گەشت (30s–1m):
  4–6 ڕاستیی سەرسوڕهێنەر، هەر یەکە ڕستەیەکی کورت + یەک وێنە.
  یان: کەسی دووەم «تۆ...» و هەستی جەستەیی.

وەرچەرخان (~1m):
  «ئۆهۆ، چی بووە؟» / «ئەو خاڵە دەبینن؟» — 3 پرسیاری یەک لە دوای یەک.

ڕوونکردنەوە (1:00–1:30):
  بیرۆکەی زانستی بە 3 ڕستەی سادە. بێ هاوکێشە.

هەست (1:30–2:00):
  ماڵ، تەنیایی، کات، کۆتایی. دەنگ نزمتر بکە.

کۆتایی (2:00–2:20):
  ڕستەیەکی فەلسەفیی تیژ  یان  پرسیارێکی دوولایەنە بۆ کۆمێنت.
```

**چێکلیستی پێش تۆمارکردن**
- [ ] هووک لە ≤5 چرکەدا تەواو دەبێت؟
- [ ] تەنها یەک بیرۆکەی زانستیی سەرەکی؟
- [ ] هەر ژمارەیەک لەسەر شاشە دەنووسرێت؟
- [ ] لانیکەم یەک ساتی «تۆ»/«ئێمە» کە بینەر پەیوەندیی کەسیی پێی هەبێت؟
- [ ] وشەی «ماڵ» یان هەستێکی مرۆیی؟
- [ ] Twist لە نزیک خولەکی یەک؟
- [ ] کۆتایی: ڕستەی بیرنەچووەوە یان پرسیار بۆ کۆمێنت؟
- [ ] کەت هەر 2–5 چرکە، پانچ‌ین لە A-roll؟
