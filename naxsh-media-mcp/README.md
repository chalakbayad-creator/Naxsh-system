# Naxsh Media MCP

سێرڤەرێکی MCP ـی ئۆنڵاینە کە لەسەر Cloudflare Workers کار دەکات. لە هەر شوێنێک و لە هەر ئامێرێکەوە، تەنانەت Claude Code ـی موبایلیش، دەتوانیت ئەم کارانەی پێ بکەیت:

- **ترانسکریپت** بە Google Gemini، بە وردییەکی زۆر، بۆ کوردی (سۆرانی و کرمانجی)، عەرەبی و فارسی. ئەنجامەکە SRT ـە لەگەڵ کاتی هەر ڕستەیەک.
- **دروستکردن و دەستکاریکردنی وێنە** بە GPT Image 2.5 لە ڕێگەی Kie.ai. ئەگەر 2.5 بەردەست نەبوو، خۆکارانە 2.0 بەکار دەهێنێت.
- **قوفڵی ستایل (Style Lock)**: دیزاینە پەسەندکراوەکان هەڵدەگیرێن و لەگەڵ هەر وێنەیەکی نوێدا وەک ڕیفرێنس دەنێردرێن، بۆ ئەوەی ستایلەکە نەگۆڕێت.

```
Claude Code (موبایل/وێب) ──► /mcp/<تۆکن> ──► Cloudflare Worker ──► Gemini (ترانسکریپت)
                                              │                 └► Kie.ai (GPT Image)
                                              └─ KV (یان R2): فایل، ئەنجام، ستایل، ژمارەی بەکارهێنان
```

## سەلامەتی
- کلیلەکانی Kie و Gemini تەنها لەسەر Cloudflare وەک **Secret** هەڵدەگیرێن. بەکارهێنەر هەرگیز نایانبینێت.
- هەر کەسێک **تۆکنێکی تایبەت** وەردەگرێت. بۆ لابردنی کەسێک، تەنها تۆکنەکەی لە `ACCESS_TOKENS` دەسڕیتەوە.
- **سنووری ڕۆژانە** بۆ هەر کەسێک هەیە: بە شێوەی بنەڕەت ٦٠ وێنە و ٤٠ ترانسکریپت. ئەدمینەکان سنووریان نییە.
- لینکی ئەپلۆد واژۆکراوە، تەنها ٣٠ خولەک کار دەکات و یەک جار بەکار دێت.
- لینکی فایلەکان ناوێکی هەڕەمەکیی ٢٤ پیتییان هەیە، بۆیە کەس ناتوانێت بیانقۆزێتەوە. Kie پێویستی بە لینکی گشتییە بۆ ئەوەی ڕیفرێنسەکان بخوێنێتەوە.
- فایلی دەنگ دوای ترانسکریپت لە Google دەسڕدرێتەوە.
- **زۆر گرنگ:** لە داشبۆردی Kie و Google Cloud سنووری خەرجی (budget) دابنێ، وەک دوایین پاراستن.

## دانانی ئێستا
- سێرڤەر: `https://naxsh-media-mcp.akarbahir9.workers.dev`
- شوێنی هەڵگرتن: **Workers KV**، کە بەخۆڕاییە و پێویستی بە کارت نییە. هەر فایلێک تا ٢٥ MB دەبێت و دوای ٣٠ ڕۆژ خۆکارانە دەسڕدرێتەوە.
- کلیلەکانی Kie و Gemini لە پەڕەی `/setup/<تۆکنی ئەدمین>` دادەنرێن. لەوێ بە AES-GCM شاردراوە (encrypted) هەڵدەگیرێن. ئەگەر وەک Worker Secret دابنرێن، ئەوانە لە پێشترن.
- بۆ R2: ئەگەر لە داهاتوودا R2 ـت چالاک کرد، binding ـێکی R2 بە ناوی `FILES` زیاد بکە.

## دانان، هەنگاو بە هەنگاو (دەکرێت لە موبایلیشەوە بکرێت)

### ١. کلیلەکان ئامادە بکە
- **Kie:** لە https://kie.ai/api-key
- **Gemini:** لە https://aistudio.google.com/apikey

### ٢. لە Cloudflare بەکەتێک (bucket) ـی R2 دروست بکە
لە dash.cloudflare.com بڕۆ بۆ **R2 → Create bucket**، ناوەکەی بنووسە `naxsh-media-files`.

پێشنیار: لە **Settings → Object lifecycle rules** ڕێسایەک دابنێ کە فایلەکانی ناو `files/` دوای ٣٠ ڕۆژ بسڕێتەوە.

### ٣. Worker ـەکە لە GitHub ـەوە دابنێ
لە Cloudflare بڕۆ بۆ **Workers & Pages → Create → Import a repository**:
1. ڕیپۆی `Naxsh-system` هەڵبژێرە.
2. **Root directory** بکە بە `naxsh-media-mcp`.
3. **Deploy command** بکە بە `npx wrangler deploy`.

لەمەودوا هەر گۆڕانکارییەک push بکرێت، خۆکارانە دادەنرێتەوە.

### ٤. Secret ـەکان دابنێ
لە **Worker → Settings → Variables and Secrets** ئەمانە زیاد بکە، هەموویان بە جۆری **Secret**:

| ناو | نرخ |
|---|---|
| `KIE_API_KEY` | کلیلی Kie |
| `GEMINI_API_KEY` | کلیلی Gemini |
| `ACCESS_TOKENS` | `akar:تۆکنێکی-درێژ,ali:تۆکنێکی-تر` |
| `SIGNING_SECRET` | نهێنییەکی درێژی هەڕەمەکی |

بۆ دروستکردنی تۆکن یان نهێنی، بە Claude بڵێ: «تۆکنێکی هەڕەمەکیی ٤٨ پیتیم بۆ دروست بکە»، یان لە کۆمپیوتەر ئەم فەرمانە بنووسە: `openssl rand -hex 24`. هەر تۆکنێک لانیکەم ٢٤ پیت بێت.

ناوی ئەدمین لە `wrangler.jsonc` لە بەشی `ADMIN_USERS` دایە، و بە شێوەی بنەڕەت `akar` ـە. ئەگەر ناوێکی ترت لە `ACCESS_TOKENS` بەکار هێنا، ئەویش بگۆڕە.

### ٥. بیبەستەوە بە Claude
لە https://claude.ai/customize/connectors هەڵبژێرە **Add custom connector**:
- **Name:** `naxsh-media`
- **URL:** `https://naxsh-media-mcp.<subdomain>.workers.dev/mcp/<تۆکنەکەت>`

دوای ئەوە session ـێکی نوێ لە Claude Code دەست پێ بکە. ئامرازەکان ئامادە دەبن.

**بۆ کەسانی تر:** هەر کەسێک لینکی تایبەتی خۆی بە تۆکنی خۆی وەردەگرێت. لینکی خۆت مەدە بە کەس.

### ٦. سکیڵەکە زیاد بکە
فۆڵدەری `skill/naxsh-media` بکە بە zip، و لە claude.ai بڕۆ بۆ **Settings → Capabilities → Skills → Upload skill**. ئەم سکیڵە فێری Claude دەکات چۆن ئامرازەکان لەگەڵ سکیڵی مۆشن گرافیکەکەت بەکار بهێنێت.

### ٧. تاقیکردنەوە
لە Claude Code بنووسە: «status ـی naxsh-media پیشان بدە». پاشان بنووسە: `status` لەگەڵ `list_gemini_models: true`. ئەمە لیستی مۆدێلەکانی Gemini دەهێنێت کە کلیلەکەت دەتوانێت بەکاریان بهێنێت. ئەگەر مۆدێلێکی Pro ی نوێتر لە `gemini-3.1-pro-preview` هەبوو، `GEMINI_MODEL` لە `wrangler.jsonc` بگۆڕە.

> ئەگەر Claude نەیتوانی فایل ئەپلۆد یان دابەزێنێت (هەڵەی `blocked`)، هۆستی Worker ـەکە (`naxsh-media-mcp.<subdomain>.workers.dev`) بخەرە لیستی **allowed hosts** ـی environment ـەکەت لە ڕێکخستنەکانی Claude Code.

## ئامرازەکان

| ئامراز | کار |
|---|---|
| `file_upload_link` | لینکی ئەپلۆد بۆ فایلێکی ناوخۆیی، لەگەڵ فەرمانی curl |
| `file_import_url` | هێنانی فایلێک لە لینکێکی https |
| `transcribe` | ترانسکریپتی ورد بە دوو جار گوێگرتن، و ئەنجامی SRT + JSON |
| `image_generate` | دروستکردنی وێنە، بە `style` ـەوە یان بەبێ ئەو |
| `image_edit` | دەستکاری یان دیزاین لەسەر وێنەیەک. وێنەی یەکەم بنەڕەتە |
| `image_result` | هێنانی ئەنجامی وێنەیەک کە هێشتا ئامادە نەبووە |
| `style_save` / `style_get` / `style_list` | بەڕێوەبردنی قوفڵی ستایل |
| `status` | بەکارهێنانی ئەمڕۆ، سنوورەکان و مۆدێلەکان |

## پاراستنی ستایل: بۆچی دەگۆڕێت و چۆن چارەسەر کراوە
لە چاتی ChatGPT ـدا وێنە پێشووەکان لەناو گفتوگۆکەدا دەمێننەوە، بۆیە مۆدێلەکە ستایلە پەسەندکراوەکە دەبینێت. بەڵام هەر بانگکردنێکی API لە سفرەوە دەست پێ دەکات و هیچ لە پێشوو نازانێت.

چارەسەرەکە: کاتێک دیزاینێک پەسەند دەکەیت، Claude بە `style_save` هەڵیدەگرێت، لەگەڵ تێبینیی ستایلەکە (کۆدی ڕەنگەکان، ڕێژەی شووشە، جۆری glow و هتد). لەوە بەدواوە هەر وێنەیەکی نوێی هەمان پرۆژە، ئەو دیزاینانە وەک ڕیفرێنس لەگەڵ خۆی دەبات (تا ١٥ دانە)، و بەشێکی **STYLE LOCK** بۆ پرۆمپتەکە زیاد دەکرێت.

ئەمە تەنانەت لە چاتیش بەهێزترە، چونکە لە چاتێکی درێژدا مۆدێلەکە وردە وردە ستایلە سەرەتاییەکە لەبیر دەکات، بەڵام لێرەدا ڕیفرێنسەکان هەموو جارێک بە ڕوونی دەنێردرێنەوە.

## ترانسکریپت: بۆچی وردە
- مۆدێلێکی گشتیی Gemini بەکار دەهێنرێت، لەگەڵ ڕێنمایی تایبەت بۆ ڕێنووسی سۆرانی (ک ی ە، نەک ك ي ة)، کرمانجی (پیتی لاتینیی هاوار)، عەرەبی و فارسی (ZWNJ).
- قسەکە وشە بە وشە دەنووسرێت: وەرناگێڕدرێت، کورت ناکرێتەوە، و وشەی بیانی بە زمانی خۆی دەنووسرێت.
- **دوو جار گوێ دەگرێت:** جاری دووەم بە دەنگەکەدا دەچێتەوە و هەڵەکانی ڕەشنووسی یەکەم ڕاست دەکاتەوە.
- `glossary` ڕێنووسی ناو و براندەکان جێگیر دەکات.
- کاتەکان بە میلیچرکە دەدرێن، و هەر ڕستەیەک کورتە (٦ چرکە و ٤٢ پیت) بۆ ئەوەی وەک سەبتایتڵ گونجاو بێت.
- بۆ ڤیدیۆی درێژ، Claude دەنگەکە دەکات بە پارچەی ٥ خولەکی، چونکە کاتی پارچەی کورتتر وردترە.
- مۆدێلی تایبەتی Google بۆ قسە (`gemini-3.5-transcribe`) وەک بژاردەی `engine: "speech"` بەردەستە. بەڵام هێشتا پشتڕاست نەکراوەتەوە کە پشتگیریی کوردی دەکات.
