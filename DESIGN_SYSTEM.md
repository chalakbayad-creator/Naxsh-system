# Naxsh UI Design Rules

These rules apply to every current and future screen in this project:

- Keep interfaces minimal, calm, and easy to scan.
- Never use busy, decorative, or visually noisy page backgrounds.
- Avoid gradients in UI controls and structural backgrounds unless the user explicitly requests one.
- Prefer solid white or soft neutral surfaces with subtle borders.
- Use generous, balanced spacing and clear visual hierarchy.
- Avoid excessive rounded corners, shadows, badges, chips, and decorative elements.
- Keep actions lightweight; icons and buttons should be simple and unambiguous.
- Preserve the Naxsh brand palette as restrained accents, not large decorative fills.
- Use the NRT Regular font throughout the system.
- Every module opens as its own full screen and includes a clear, lightweight route back to the dashboard.
