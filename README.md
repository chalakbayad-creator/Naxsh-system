# Naxsh System

سیستەمی بەڕێوەبردنی چاپخانەی نەخش، بە دیزاینی RTL و فۆنتی کوردی NRT.

## وەشانەکان

ئەم پڕۆژەیە Semantic Versioning بەکاردەهێنێت:

- `MAJOR`: گۆڕانکارییە گەورە و ناگونجاوەکان
- `MINOR`: تایبەتمەندیی نوێ
- `PATCH`: چاککردنەوە و وردەگۆڕانکاری

هەر وەشانێک بە Git commit و tag ـێکی وەک `v1.0.0` پاشەکەوت دەکرێت، بۆیە گەڕانەوە بۆ هەر وەشانێکی کۆن ئاسانە.

## کردنەوە

`index.html` لە وێبگەڕ بکەرەوە، یان لە ناو بوخچەکەدا local server ـێک دەست پێ بکە.
